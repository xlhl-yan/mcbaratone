# 手册/

给 DSH 会话读的操作手册（mcbaratone 陪玩项目）。放在仓库里，别的 DSH 拉到代码就能看到。

| 文件 | 谁读 | 讲什么 |
| --- | --- | --- |
| `空闲自主行为手册.md` | 被 `[autonomy]` 叫醒的 AI | 角色闲着时怎么用 **DSH 的 goal 机制**（`get_goal` / `create_goal` / `update_goal`）立目标、拆步骤、一轮推进一步 |
| `游戏态势应对手册.md` | 处理「（游戏态势）」消息的会话 | 低 token 查表：什么情况该动、什么情况只回一个「等」字 |

## 和根目录副本的关系：手动同步

工作区根目录也有同名两份（给人顺手看）。**仓库这份是正本**，两边手动同步：

```powershell
# 仓库 → 工作区根
Copy-Item <REPO>\手册\*.md "<工作区根>\" -Force
# 或者反过来（在工作区根改完）
Copy-Item "<工作区根>\*.md" <REPO>\手册\ -Force
```

同 `plugins/` 的规矩：**不用 link，改完手动同步**。
改完哪边，顺手核一下两份的哈希一致，别让它们漂。
