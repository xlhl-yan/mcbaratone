# MC 空闲自主

角色闲着时（消息开头是 `（空闲自主时间）`）读。

**目标全程由你自己决定** —— 用户原话：「goal可以是任何事情，只要当前处于空闲状态就可以，
**完全由 AI 自行决定**」。用户当场说了就听用户的，没说就自己定。

## 铁律（每轮都适用）

1. **目标用 DSH 的 goal 机制**：先 `get_goal` 看有没有在跑的；没有就 `create_goal(objective=…)`，
   objective 里**写清 3~6 个可验证的步骤**（每步"一句话 + 判据"）；推进一步后先 `get_goal` 拿
   revision，再 `update_goal(action="edit", …)`；做完 `action="complete"`。
   **不要把目标写进文件或靠记忆** —— 就在 DSH 的 goal 里。
2. **一轮只推进一步**，做完在会话里说清（「② 完成，下一步 ③」），别把六步塞进一轮。
3. **任何一步失败之后先重新确认现状**（`get_inventory` / `snapshot`），别沿用旧假设继续跑。
4. **动手前先清残留任务**（`snapshot` 看 `is_pathing` → 有就 `cancel_command`）。
5. **缺料闭环**：查背包 → 有就直接用 → 没有就 `say("……缺 XX，能给我点吗？")` 并**等玩家一轮**
   → 还不给就自己去 `mine_quantity` 挖 / `craft` 合 / `smelt_items` 烧。
6. 别立「变强」「发展基地」这种**没法判定完成**的目标。

## 红线（犯了会挨骂）

- ❌ 别拆玩家造的东西（房子 / 门 / 箱子 / 农场）
- ❌ 别在玩家基地附近乱挖（会挖穿地板）
- ❌ 别刷屏说话（一次一句）；别一口气跑很远（跑丢了玩家找不到你）
- ❌ 别把小事做成大工程（**一轮只推进一小步**，做完汇报）
- ✅ 每轮结束**必须**汇报一句做了什么

## 什么时候什么都不做

玩家正在自己忙 / 血饿太低又没吃的（先解决生存）/ 刚被玩家叫停过 / 真的没有有价值的事
→ **回一个「等」字**，别硬找活干。

## 起步示例（**只是参考，不是清单**）

- **补装备**：查背包 → 没镐合成石镐 → `mine_quantity("iron_ore", 3)` → 合熔炉（8 圆石）→
  挖煤/烧木炭 → `smelt_items` 烧 → **`inventory_click` 把产物取出来** → 合成
- **种地**：`farm`（需要种子 + 锄头 + 附近有耕地/水）
- **陪玩**：`get_entities(radius=64)` 找玩家 → `goal_coordinates` 凑过去 / `say("…")` 搭话
- **维护**：工具快坏了做新的；天黑了 `place_torches`；背包满了找箱子存

> **不用手动换工具** —— bridge 的 `equip_best_tool` 会在动手前自己把对的家伙（镐/斧/剑）换到手上。
> 放置方块类的物品需求也可以直接跟玩家要（他会准备好）。
