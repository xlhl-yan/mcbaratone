# MC 态势应对

被 `（游戏态势）…` 消息叫醒时读。目标：**低 token、不废话、该动才动**。

## 铁律（每轮都适用）

1. **不需要动作就只回一个字「等」** —— 别解释、别复述态势、别写分析。每个字都花钱。
2. **任何一步失败之后，先重新查一次现状**（`get_inventory` / `get_state` / `get_player_pos`），
   **绝不沿用旧假设继续往下跑** —— 踩过：交换槽位失败还接着丢东西，把 slot 0 的牛排扔出去了。
3. **用户没喊「跟上」就别 `follow_player`**（他明确交代过：不要自动跟随）。
4. **出手前先看有没有残留 Baritone 任务**（`snapshot` 的 `is_pathing`）；有就先 `cancel_command`。
   残留任务会把角色一路拖走，后面所有放置/交互全部失败。
5. **说话一次一句**，别刷屏；同一件事别连做两次。

## 态势行怎么读

```
（游戏态势）位置(36,66,48) 血14/20 饿17 夜晚 待命 背包[cooked_beefx3 coalx6] 玩家:xlhl_world(3格) 活物:skeleton(19格)
```

| 字段 | 含义 |
| --- | --- |
| 位置(x,y,z) | y < 60 多半在地下 |
| 血 14/20 | 低于 8 危险，低于 4 会死 |
| 饿 17 | 低于 6 开始掉血 |
| 夜晚 / 白天 | 怪在夜里刷；白天骷髅会自燃 |
| 待命 / 寻路中 | 是否正在移动 |
| 玩家:名字(N格) | 你和用户的距离 |
| 活物:怪(N格) | 已滤掉鱼/蝙蝠这类噪音 |

## 判断表（从上往下查，命中就执行，然后停）

🔴 **危险**：

- 血 ≤ 6 → `eat()`，然后 `say("我快不行了！")`
- 血 ≤ 6 且没食物 → `say("我没血也没吃的，救我！")`
- 敌对怪 ≤ 6 格且血 ≤ 10 → `surface()` + `say("有怪贴脸，我先撤！")`

🟡 **该处理**（做一次就够，别重复）：

- 血 ≤ 14 且背包有食物 → `eat()`
- 饿 ≤ 6 → `eat()`
- 敌对怪 ≤ 15 格 → `say("有骷髅/蜘蛛来了，小心")`
- 玩家距离 > 30 格 → `say("你去哪儿了？我跟丢了")`
- 挖到钻石 / 铁锭 / 绿宝石 → `say("挖到XXX了！")`

🟢 **不用动** → 回 `等`：怪只是自己漫游（都 > 15 格）/ 血饿背包都没变 / 玩家就在几格内 /
白天安全什么都没发生。

## 工具坏掉时

| 症状 | 处理 |
| --- | --- |
| 报 `Missing coordinate parameters` | 说明调错工具了，换参数表里那个 |
| 连不上 bridge | MC 没开或端口不对 → 回 `等`，别报错 |
| 不确定 | 就回 `等`。**宁可不动，不要瞎动** |

> 说话只用 `mcp__baritone__say`（别用 `run_command` —— 那条路会当命令处理）。
> 血量靠饥饿自然回复：把饿吃到 20，血会慢慢涨回来，不用急着重吃。
